## Завдання 2
Інтеграл функції f(x) = x² на відрізку [0, 2] було обчислено методом Монте-Карло та перевірено за допомогою
функції quad з бібліотеки SciPy.

Аналітичне значення:
∫ x² dx = 8/3 ≈ 2.6667

Метод Монте-Карло показав близьке значення, а похибка зменшується зі збільшенням кількості випадкових точок.

### Висновок
Метод Монте-Карло є ефективним наближеним методом чисельного інтегрування, що підтверджується порівнянням з точним результатом.
